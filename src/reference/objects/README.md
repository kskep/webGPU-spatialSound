# reference/objects

Edw sxediazw ta antikeimena pou fainontai sto viewport. Afta ta modules aforoun tin provoli, oxi tous ypologismous diadosis tou ixou.

## Arxeia

- [probe-renderer.ts](probe-renderer.ts): Sxediazw ta probe spheres me thesi, aktina kai xrwma ana instance. Ta xromata deixnoun bake state kai epilogi.
- [scene-object-renderer.ts](scene-object-renderer.ts): Sxediazw ta box objects tis skinis kai ta xromatizw analoga me to material tous. Xrisimopoiw ta idia SceneObject dedomena me tin akoustiki geometria.
- [sphere-renderer.ts](sphere-renderer.ts): Sxediazw ti sfaira tis pigis me WebGPU. Etoimazw sphere geometry, matrices kai lighting gia na fainetai i thesi tis.
